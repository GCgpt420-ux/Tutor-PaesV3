# TutorPAES Frontend

Este repositorio contiene el frontend en Next.js para la plataforma TutorPAES.

 **Importante:** el proyecto se está migrando de Supabase a un backend propio
(FastAPI). Cualquier mención a Supabase en el código se ha eliminado; el
cliente HTTP personalizado (`apiFetch`) realiza llamadas al backend.

Para configurar y ejecutar en desarrollo, consulte la documentación del backend
y el README principal del monorepo.
